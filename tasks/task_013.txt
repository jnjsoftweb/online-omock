알려진 강력한 위치에 대한 AI 성능 테스트. 검색 깊이 및 응답 시간 벤치마크. 적절한 도전을 위해 다양한 난이도 수준 비교.

# Subtasks:
## 1. Implement Minimax Algorithm with Alpha-Beta Pruning [deferred]
### Dependencies: None
### Description: Create the core minimax algorithm with alpha-beta pruning for efficient game tree search
### Details:
Implementation details:
1. Create a new class `AdvancedAI` that extends the existing AI functionality
2. Implement the minimax algorithm that recursively evaluates game states
3. Add alpha-beta pruning to eliminate branches that won't affect the final decision
4. Include configurable search depth parameters for different difficulty levels
5. Create utility functions to generate and evaluate possible moves
6. Test the implementation by comparing move selection against basic AI
7. Verify that alpha-beta pruning reduces the number of evaluated nodes while producing identical results to a full minimax search
