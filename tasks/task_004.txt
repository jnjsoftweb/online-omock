# Task ID: 4
# Title: 핵심 게임 로직 구현
# Status: pending
# Dependencies: 1
# Priority: high
# Description: 보드 표현, 착수 유효성 검사, 승리 조건 확인을 포함한 오목의 핵심 게임 로직 개발
# Details:
보드 표현(15×15 및 19×19 옵션)이 포함된 게임 상태 모델 생성. 합법적인 착수를 보장하는 착수 유효성 검사 로직 구현. 가로, 세로, 대각선 방향의 5목 승리 조건 확인 알고리즘 개발. 흑돌과 백돌 간 교대를 위한 턴 관리 시스템 추가. 구성 가능한 옵션으로 게임 규칙 변형(렌주 규칙, 삼삼 제한) 구현. 게임 상태 조작 및 직렬화를 위한 유틸리티 함수 생성.

# Test Strategy:
착수 유효성 검사, 승리 조건 확인 및 규칙 적용을 위한 단위 테스트 생성. 보드 경계와 특수 규칙 시나리오와 같은 엣지 케이스 테스트.

# Subtasks:
## 1. 게임 상태 모델 및 보드 표현 구현 [pending]
### Dependencies: None
### Description: 오목 게임의 상태를 표현하는 모델과 15×15 및 19×19 크기의 보드 표현 구현
### Details:
1. GameState 클래스 생성 - 현재 보드 상태, 현재 턴, 게임 종료 여부 등을 저장
2. 보드 크기를 설정할 수 있는 옵션 구현 (15×15, 19×19)
3. 보드 상태를 2차원 배열로 표현 (0: 빈 칸, 1: 흑돌, 2: 백돌)
4. 보드 초기화 메서드 구현
5. 보드 상태를 시각적으로 표현하는 메서드 구현 (디버깅용)
6. 게임 상태의 직렬화/역직렬화 메서드 구현 (JSON 형식)
7. 테스트: 다양한 보드 크기 초기화 및 상태 표현 정확성 검증

## 2. 착수 및 턴 관리 시스템 구현 [pending]
### Dependencies: 4.1
### Description: 돌을 놓는 착수 기능과 흑백 간 턴 교대를 관리하는 시스템 구현
### Details:
1. makeMove(x, y) 메서드 구현 - 주어진 좌표에 현재 턴의 돌을 놓음
2. 착수 후 턴 교대 로직 구현 (흑 → 백 → 흑)
3. 이미 돌이 놓인 위치에 착수 시도할 경우 예외 처리
4. 보드 범위를 벗어난 착수 시도 시 예외 처리
5. 게임이 이미 종료된 상태에서의 착수 시도 시 예외 처리
6. 마지막 착수 위치 저장 기능 추가 (UI 하이라이트용)
7. 테스트: 착수 기능 정상 작동 확인, 턴 교대 정확성 검증, 예외 상황 처리 테스트

## 3. 승리 조건 확인 알고리즘 개발 [pending]
### Dependencies: 4.1, 4.2
### Description: 가로, 세로, 대각선 방향으로 5개 돌이 연속되는 승리 조건 확인 알고리즘 구현
### Details:
1. checkWin(x, y) 메서드 구현 - 마지막 착수 위치에서 승리 조건 확인
2. 가로(→, ←) 방향 연속 돌 검사 알고리즘 구현
3. 세로(↑, ↓) 방향 연속 돌 검사 알고리즘 구현
4. 대각선(↗↙, ↖↘) 방향 연속 돌 검사 알고리즘 구현
5. 모든 방향에서 연속된 같은 색 돌이 5개 이상인 경우 승리 판정
6. 승리 판정 시 게임 종료 상태 설정 및 승자 정보 저장
7. 테스트: 다양한 승리 패턴에 대한 검증 (가로, 세로, 대각선 승리), 경계값 테스트

## 4. 게임 규칙 변형 구현 (렌주 규칙, 삼삼 제한) [pending]
### Dependencies: 4.1, 4.2, 4.3
### Description: 렌주 규칙과 삼삼 제한 등 오목의 다양한 규칙 변형을 구성 가능한 옵션으로 구현
### Details:
1. GameRules 클래스 생성 - 게임에 적용될 규칙 옵션 정의
2. 삼삼 제한 검사 알고리즘 구현 (흑돌이 두 개의 열린 3을 동시에 만드는 착수 금지)
3. 사사 제한 검사 알고리즘 구현 (필요시)
4. 장목 규칙 구현 (5개 초과 연속 돌에 대한 처리)
5. 렌주 규칙 구현 (흑은 삼삼/사사/장목 제한, 백은 제한 없음)
6. 규칙 위반 착수 시도 시 예외 처리 및 메시지 반환
7. 규칙 설정을 게임 초기화 시 옵션으로 지정할 수 있도록 구현
8. 테스트: 삼삼 제한 상황 테스트, 렌주 규칙 적용 시 흑/백 차등 규칙 검증

## 5. 게임 상태 조작 및 유틸리티 함수 개발 [pending]
### Dependencies: 4.1, 4.2, 4.3, 4.4
### Description: 게임 상태 관리, 기록, 복원 등을 위한 다양한 유틸리티 함수 개발
### Details:
1. 게임 기록 저장 및 불러오기 기능 구현 (수순 기록)

5. 보드의 특정 위치에 착수 가능 여부 확인 메서드 구현 (모든 규칙 고려)
6. 현재 게임 상태의 복사본 생성 메서드 구현 (시뮬레이션용)
7. 디버깅 및 로깅 유틸리티 함수 구현
8. 테스트: 게임 상태 저장/불러오기 정확성 검증, 무르기 기능 테스트, 착수 가능 여부 판단 정확성 테스트
