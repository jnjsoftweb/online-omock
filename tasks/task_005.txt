# Task ID: 5
# Title: HTML5 Canvas를 사용한 게임 보드 UI 구현
# Status: pending
# Dependencies: 1, 4
# Priority: high
# Description: HTML5 Canvas를 사용하여 반응형 디자인의 대화형 게임 보드 UI 생성
# Details:
게임 보드 렌더링을 위한 Canvas 컴포넌트 생성. 다양한 크기(15×15, 19×19)의 보드 그리기 함수 구현. 적절한 흑백 스타일링의 돌 렌더링 추가. 격자선 및 좌표 마커 구현. 돌 배치를 위한 마우스/터치 상호작용 핸들러 생성. 유효한 착수 위치, 마지막 착수 표시기 및 승리 조건에 대한 시각적 피드백 추가. 다양한 화면 크기에 대한 반응형 스케일링 보장. 돌 배치를 위한 기본 애니메이션 구현.

# Test Strategy:
다양한 화면 크기와 기기에서 렌더링 테스트. 터치 및 마우스 상호작용이 올바르게 작동하는지 확인. 시각적 피드백 요소가 적절히 표시되는지 확인.
