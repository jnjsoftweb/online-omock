# Task ID: 6
# Title: 게임 보드 UI 구현 (HTML5 Canvas)
# Status: pending
# Dependencies: 1,4
# Priority: high
# Description: HTML5 Canvas를 사용하여 반응형 게임 보드 UI 구현
# Details:
게임 보드 렌더링을 위한 Canvas 컴포넌트 생성. 다양한 크기(15×15, 19×19)의 보드 그리기 함수 구현. 흑백 돌 렌더링 스타일링 구현. 격자선과 좌표 표시 구현. 돌 배치를 위한 마우스/터치 상호작용 핸들러 구현. 유효한 착수 위치, 최근 착수 표시, 승리 조건에 대한 시각적 피드백 추가. 다양한 화면 크기에 대한 반응형 스케일링 구현. 돌 배치에 대한 기본 애니메이션 구현.

# Test Strategy:
다양한 화면 크기와 기기에서의 렌더링 테스트. 터치 및 마우스 상호작용이 올바르게 작동하는지 확인. 시각적 피드백 요소들이 제대로 표시되는지 확인.
